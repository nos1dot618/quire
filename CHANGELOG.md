## [0.1.0] - 2026-10-23

First public version.

### Added

- Documents of named cells, each holding any mix of text, Markdown, code, links, images, animated GIFs, file references, attachments and dividers.
- The `.quire` format: a ZIP with a versioned JSON manifest and original asset bytes, atomic saves, validation, id repair and a migration pipeline.
- Paste and drag-and-drop of images, files, URLs and text.
- Rendered Markdown and syntax-highlighted code previews.
- Document-wide undo and redo, and crash-recovery drafts.
- Export to Markdown, PDF, HTML and plain text.
- Find, recent documents, zoom, full screen and keyboard shortcuts.
- Light, dark and high-contrast themes, and per-monitor DPI awareness.
- An application icon.
